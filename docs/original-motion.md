# 原版动效保留

`src/original-word-motion.js` 的 `BEGIN ORIGINAL` / `END ORIGINAL` 之间，直接复制用户提供的 `词序/index.html` 中从 `let motionLayer` 到 `playWordMotion` 的完整原文，仅将 CRLF 统一为 LF。函数名、选择器、轨迹、片段数量、时序、缓动、模糊和清理时间均未改写。

原文块 SHA-256：`eca8d54140c8e0c866b78ff231d305ce73b482322702692ce2a2f2ed8be1f0b3`。

`src/original-word-motion.css` 同样直接复制原文件的动效 CSS，SHA-256：`eff66b01cf2117b3020999c2995461cbf972251815953246fc320db0d9e1237e`。

原版引擎留作原文档案与翻页基础，外层注入 `$` 和 `current`，把 word-stage / summary-view 映射到现有学习区。`.word-stage` 作为兼容类名保留。用户关闭动态效果时跳过动画，系统减少动态效果同样生效。

按后续设计，“记住了”与撤回记住的当前播放实现位于 `src/master-motion.js`，采用原切分位置与飞散方向，分别正放分离与逆向合拢；原档案函数不改写。“上一个”采用反向翻页，独立于恢复记住状态。旧词克隆默认透明，退场完成即移除；合拢期间隐藏真实词层，结束后统一交还显示，防止取消动画时旧词回弹与重影。

切片分离采用 480 / 520ms，离开时略微放大、模糊并淡出，合拢约 600ms。24 枚 4–7px 方块与 16 枚细碎片保持透明静止态，部分粒子使用蓝色强调，结束或取消后移除；逆向时碎片向切口回收。

划线保留原倾斜角，以裁剪从右上端向左下端揭示，约 187ms 完成、340ms 内淡出，方块粒子随方向先右后左迸出。控件字重与荧光笔延续个人文档站的交互方向；大单词额外参考 Text Pressure 的鼠标距离响应，仅调整本地思源宋体字重与主题色，使用 em 固定字宽，缩放屏幕时同步适配，并响应减少动态效果设置。

悬停的水平作用半径最多 0.65em，短词再收窄；范围外维持原字重 900，中心可降至 360，边缘平滑衰减至零。接近与离开使用同一逐帧一阶阻尼，时间常数分别为 55 / 110ms，无弹簧超调；移除额外的 CSS 字重 / 颜色过渡，避免叠加延迟。离场只恢复此前受到影响的字母，切词、关闭动效或隐藏页面时直接清理。

纯静态网页只能通过浏览器提供的 `navigator.vibrate` 请求震动。[兼容性说明](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate)标记其可用性有限；iPhone Safari 不支持。按用户要求，本次不进行震动设备验证，不使用绕过浏览器限制的模拟开关技巧。音效已按用户后续指示移除，只保留禁用的「后续开发」入口；无音频资源加载或播放逻辑。
